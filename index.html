Panduan Format Kolom Impor

Agar proses impor data berjalan mulus tanpa kegagalan skema, pastikan file .csv atau .xlsx Anda memiliki baris header dengan susunan 5 kolom berikut:

Tanggal Tipe Kategori Nominal Deskripsi
2026-10-25 Pemasukan Gaji Pokok 10000000 Gaji Bulanan
2026-10-26 Pengeluaran Makanan 75000 Makan siang
  • Tanggal: Format disarankan YYYY-MM-DD (contoh: 2026-10-28).
  • Tipe: Ditulis Pemasukan / Pengeluaran (atau income / expense).
  • Nominal: Angka murni (misal: 50000 atau 50.000).
